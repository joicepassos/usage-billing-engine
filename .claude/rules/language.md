# Language
- Everything committed to the repository is in English: code, identifiers, comments, commit messages, PR descriptions, README, PRD, ADRs, plans, test names.
- Talk to the user in the language they write in. If they write in Portuguese, reply in Portuguese, but keep every file you write in English.
- Domain terms follow `CONTEXT.md`. Brazilian fiscal terms keep their official names where translation would lose meaning (NFS-e, DPS, IBS, CBS, ISS, CNPJ, CPF, Pix, boleto) and are defined in `CONTEXT.md`.
